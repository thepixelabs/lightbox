# Masking, local adjustments, and retouching (Lightroom Classic + cloud Lightroom)

Lightroom's local-editing system is built around a unified Masking panel in which every "mask" is a named container holding one or more components. Each component is a primitive — a paintable brush stroke set, a linear or radial gradient, a range selection (color, luminance, or depth), or an AI-generated segmentation — and components combine through boolean operations: add, subtract, and intersect (Adobe implements intersect as subtracting the inverse of a component). The AI segmentations are the headline capability: Select Subject, Select Sky, Select Background, Select Objects (rough brush/box converted to a precise object outline), Select People with per-person, per-body-part granularity (facial skin, body skin, eyebrows, eye sclera, iris and pupil, lips, teeth, hair, facial hair, clothes), and the newer Select Landscape which parses scenes into sky, vegetation, water, mountains, architecture, snow, and natural/artificial ground. Masks are visualized through several overlay modes (color overlay, image-on-black/white, white-on-black, etc.), can be renamed, duplicated, inverted, hidden, and copied or synced across photos with AI components recomputed per image; they also travel inside "adaptive" presets.

Every mask drives an essentially full copy of the develop slider set, grouped into Tone (exposure, contrast, highlights, shadows, whites, blacks), Color (temperature, tint, hue with fine-tune, saturation, plus a color tint swatch and, in recent versions, per-mask Point Color), Presence (texture, clarity, dehaze), and Detail (sharpness, noise, moiré, defringe), topped by an Amount slider that scales the whole recipe; the cloud-based Lightroom additionally offers a per-mask tone curve with a saturation-refinement control. The brush primitive has size, feather, flow, and density controls, an erase mode, tablet pressure support, and an Auto Mask option that snaps strokes to edges. Range masks offer eyedropper/rectangle sampling with refine/smoothness falloff controls, and depth range masking works where a depth map exists (e.g., smartphone portrait HEICs, or ML-estimated depth in the cloud app).

Retouching is handled by the Remove tool (formerly Heal/Spot Removal), which is fully non-destructive: each correction remains an editable object whose source can be dragged, resized, feathered, or deleted later. It offers four engines — Clone (exact copy), Heal (source texture blended to destination color/tone), Content-Aware Remove (local patch synthesis over an arbitrary brushed region, with refresh and manual source override), and Generative Remove (Firefly diffusion inpainting in the cloud, offering an object-aware mask refinement option and three selectable variations per generation, roughly 1024px generation tiles). Supporting tools include Visualize Spots — a thresholded edge-map view for finding sensor dust — and a dedicated Red Eye tool with Red Eye and Pet Eye modes (pupil size and darken sliders; catchlight insertion for pets). For an open-source clone, the mask architecture, gradients, brush, range masks, and the full per-mask slider pipeline are the non-negotiable core; subject/sky segmentation is achievable today with open models (SAM2, BiRefNet, SegFormer), while body-part parsing and diffusion inpainting are the most expensive items.

## Feature inventory

| Feature | Priority | Complexity | Description | Building blocks |
|---|---|---|---|---|
| **Unified masking panel with component-based masks** | must | high | Each mask is a named group of one or more components (brush, gradients, range selections, AI selections) that are combined into a single grayscale weight map driving one set of local adjustments. The panel lists all masks and their components with per-item controls. | darktable's drawn+parametric mask model (reference architecture), GEGL buffers, OpenCV for mask raster ops, XMP sidecar storage (Exempi, exiv2) |
| **Add / Subtract / Intersect mask operations** | must | medium | Any component can be added to or subtracted from a mask, and masks can be intersected with a new component (implementable as subtract-of-inverse). This lets users build compound selections like 'sky minus buildings intersected with a luminance range'. | Simple per-pixel min/max/multiply compositing on GPU (wgpu/OpenGL shaders), OpenCV bitwise ops for CPU path |
| **Brush mask with flow, density, feather, and erase** | must | medium | Freehand paintable mask with size, feather (soft edge), flow (buildup rate per stroke), and density (maximum opacity cap) controls, an erase mode, keyboard size/feather shortcuts, and stylus pressure sensitivity. | libmypaint brush engine, Krita brush engine code (reference), stamp-based Gaussian-falloff dab rendering on GPU |
| **Auto Mask (edge-aware brushing)** | should | medium | Optional brush mode that confines paint to regions with color/contrast similar to the pixels under the brush center, so strokes snap to edges without careful painting. | Guided filter (OpenCV ximgproc), SLIC superpixels, color-similarity flood constraint as in GIMP's paint-select |
| **Linear gradient mask** | must | low | Directional fade defined by three parallel lines (start/midpoint/end) that can be dragged, rotated, and stretched on-canvas; classic tool for darkening skies or brightening foregrounds. | Analytic gradient evaluation in a fragment shader; on-canvas gizmo via the app's UI toolkit |
| **Radial gradient mask** | must | low | Elliptical mask with adjustable center, radii, rotation, and feather, applicable inside or outside the ellipse (invert); draggable and resizable directly on the image. | Analytic superellipse/ellipse falloff in a shader |
| **Luminance range mask** | must | medium | Selects pixels within a tonal range using a two-handled range control with falloff/smoothness handles, an eyedropper or drag-rectangle sampler, and a 'show luminance map' visualization. Commonly intersected with other components to restrict them by brightness. | Per-pixel smoothstep window on luma channel (shader), histogram UI from any charting/immediate-mode UI lib |
| **Color range mask** | must | medium | Selects pixels similar to a sampled color (eyedropper point or rectangle sample) with a refine slider controlling tolerance/falloff; supports inversion and intersection with other components. | Chromaticity-distance thresholding in a perceptual space (Oklab/CIELAB) via colour-science or littlecms; GPU shader implementation |
| **Depth range mask** | could | high | Selects by distance-from-camera using an embedded depth map (smartphone portrait HEIC) or an ML-estimated depth map, with the same range+falloff UI as luminance masks. | libheif (extract auxiliary depth images), Depth Anything V2, MiDaS/ZoeDepth, ONNX Runtime / Core ML for inference |
| **Select Subject (AI)** | must | high | One-click segmentation of the main subject into a soft-edged mask component that behaves like any other component (can be added to, subtracted from, intersected, inverted). | Segment Anything (SAM/SAM2), BiRefNet, U2-Net / IS-Net (rembg), MODNet, ONNX Runtime |
| **Select Sky (AI)** | must | high | One-click sky segmentation producing a feathered mask that handles horizon detail, trees, and haze boundaries; typically paired with an inverted copy for foreground edits. | SegFormer or DeepLabv3+ trained on ADE20K (sky class), SkyAR/sky-segmentation models, ONNX Runtime |
| **Select Background (AI)** | should | low | One-click mask of everything that is not the detected subject (and optionally not sky), useful for blurring, darkening, or desaturating surroundings. | Complement of the subject/sky masks already computed (per-pixel 1-x) |
| **Select Objects (AI, prompt-based)** | should | high | User roughly brushes or drags a box over any object and the app converts it into a precise object mask; effectively interactive promptable segmentation. | SAM/SAM2 with box and mask prompts, EfficientSAM / MobileSAM for on-device speed |
| **Select People with body-part granularity (AI)** | could | very-high | Detects each person in the photo, lets the user pick one or several, then generates masks for the entire person or specific parts: facial skin, body skin, eyebrows, eye sclera, iris and pupil, lips, teeth, hair, facial hair, and clothes — with an option to create one combined mask or separate masks per part. | BiSeNet face-parsing (CelebAMask-HQ), SCHP / LIP human parsing, MediaPipe Face Mesh, RetinaFace/YOLO for person-face detection, ViTMatte/FBA Matting for hair edges |
| **Select Landscape scene parsing (AI)** | could | high | Segments a landscape photo into selectable material classes — sky, vegetation, water, mountains, architecture, snow, natural ground, artificial ground — and creates a combined or per-class set of masks in one action. | SegFormer / Mask2Former on ADE20K, OneFormer, ONNX Runtime |
| **Mask management: rename, duplicate, invert, hide, delete, convert** | must | medium | Per-mask and per-component actions: rename masks, duplicate a mask, duplicate-and-invert (for complementary edits), toggle a mask's effect on/off, invert individual components, convert a component between add and subtract, and delete masks or components. | Plain application-model work; serialize to the sidecar edit format |
| **Mask overlay visualization modes** | must | medium | Multiple ways to see the active mask: translucent color overlay (customizable color/opacity), color overlay on B&W image, image on black/white, and white-on-black matte view; hovering a component previews just that component, with keyboard toggles for overlay and pins. | Compositing shaders; the matte views are trivial remaps of the mask buffer |
| **On-canvas pins and editing gizmos** | must | medium | Each mask component gets a draggable pin on the image; gradients expose rotate/stretch handles, radials expose feather and radius handles, and pins can be shown/hidden and dragged to reposition edits. | Custom canvas hit-testing; egui/Qt/GTK overlay drawing |
| **Full per-mask adjustment slider set** | must | very-high | Each mask carries its own copy of most develop controls, grouped as Tone (exposure, contrast, highlights, shadows, whites, blacks), Color (temp, tint, hue with fine-adjust, saturation, color tint swatch), Presence (texture, clarity, dehaze), and Detail (sharpness, noise reduction, moiré reduction, defringe). All masks' effects blend into the global pipeline non-destructively. | darktable/RawTherapee processing code as reference, LibRaw/rawspeed for decode, OpenColorIO, GPU compute (wgpu/Vulkan) or Halide for the pixel pipeline |
| **Per-mask Amount slider** | should | low | A single top-level slider that scales the entire adjustment recipe of a mask up or down, letting users tune edit strength (including preset-applied masks) without touching individual sliders. | Scalar multiply on the mask's parameter vector or on the mask buffer itself |
| **Per-mask Point Color (targeted color edit inside a mask)** | could | medium | Within a mask, sample a specific color and shift its hue/saturation/luminance with adjustable range falloff — precise color grading limited to both a region and a color. | 3D color-distance weighting in Oklab; reuse of the color-range mask math |
| **Per-mask tone curve (cloud Lightroom)** | could | medium | The cloud-based Lightroom adds a full parametric/point tone curve inside each mask, including a saturation-refinement slider to control how curve contrast affects color. | Monotone cubic/Catmull-Rom spline LUT evaluated per pixel, weighted by mask |
| **AI mask recompute and update** | should | medium | AI-generated components store their generating recipe, not just pixels: they are recomputed when the underlying image changes (e.g., after cropping or on a different photo during sync) and the panel flags stale AI masks with an update action. | Store segmentation parameters + cached raster; invalidation hooks in the edit graph |
| **Copy/sync masks across photos and adaptive presets** | should | medium | Masks copy-paste and batch-sync across photos with merge-or-replace semantics, and masks (including AI types) can be embedded in develop presets so applying the preset re-runs segmentation per image ('adaptive presets'). | Serialization of mask recipes in the preset format; per-image re-execution of AI components |
| **Non-destructive healing spot system** | must | high | Every retouch is a persistent, re-editable object: circular spots or free-form brushed regions with an automatically chosen source area that the user can drag elsewhere, resize, feather, change opacity on, or delete at any time; corrections re-render when upstream edits change. | Edit-graph node per correction; texture synthesis quality metrics for auto source search (SSD patch matching) |
| **Clone mode** | must | medium | Copies source pixels verbatim into the destination region with adjustable feather and opacity — the deterministic fallback when texture-preserving duplication is wanted. | Alpha-feathered copy composite; OpenCV for CPU reference implementation |
| **Heal mode** | must | high | Copies texture from the source region but re-matches color and luminosity to the destination surroundings so patches blend into gradients, skin, and skies invisibly. | Poisson/seamless cloning (OpenCV seamlessClone), GIMP heal tool source, mean-value coordinates cloning for speed |
| **Content-Aware Remove** | should | high | Brush an arbitrary region and the app synthesizes plausible fill from the rest of the image, with a refresh action to re-roll using a different source and the option to manually designate the sample area. Runs locally without a network. | PatchMatch (PyPatchMatch, libinpaint), LaMa (big-lama, ONNX export), MI-GAN (lightweight mobile inpainting), G'MIC multi-scale inpainting |
| **Generative Remove (diffusion inpainting)** | could | very-high | Removes objects by filling the masked region with diffusion-generated content (Adobe uses cloud Firefly); each run yields multiple selectable variations plus a refresh, and generation happens in roughly 1024px tiles which can soften very large fills. | Stable Diffusion inpainting via diffusers/ComfyUI, LaMa as a non-generative fallback, MAT transformer inpainting, local execution via ONNX/CoreML/TensorRT |
| **Object-aware removal masks** | could | high | In the Remove tool, an option converts a rough brush scribble into the detected object's precise outline (with slight expansion) before filling, so users don't need careful masking to delete a whole object. | SAM/SAM2 mask prompts, mask dilation via OpenCV morphology |
| **Visualize Spots** | should | low | A toggle plus threshold slider that renders a high-contrast inverted edge map of the image so sensor-dust spots and blemishes invisible at normal contrast become obvious while retouching. | High-pass/edge filter + threshold in a shader (Sobel or difference-of-Gaussians) |
| **Red Eye correction** | should | medium | Click-drag over an eye and the tool auto-locates the red pupil within that region, desaturates and darkens it, then exposes Pupil Size and Darken sliders to refine the fix; corrections remain editable objects. | OpenCV eye detection (Haar cascades / MediaPipe Iris), redness-ratio channel test + darkening, a well-documented classic algorithm |
| **Pet Eye correction with catchlight** | could | low | A variant of red-eye removal targeting the green/yellow retro-reflection in animal eyes, with a pupil-size control and an option to paint in an artificial catchlight since the reflection destroys the natural one. | Same detection scaffold as red-eye with different channel test; procedural radial-gradient catchlight sprite |
